codeintel-code-obfuscation-analyzer

The Relay Office. A command line wrapper that starts the external analyzers the operator selects over a directory of Python code and logs what they say, adding no analysis of its own.

The repository main.py
One directoryThe single required positional, the codebase directory; missing, it exits 1
Four instruments--bandit, --flake8, --pylint and --pyre run the tool named by each flag
Log onlyWhat the tools say is logged; no report file is written
Version--version prints main.py 1.0.0

Usage

python3 main.py DIRECTORY [--bandit] [--flake8] [--pylint] [--pyre] [--version]

Each selected analyzer runs over the directory in its own way: bandit recursively, flake8 and pylint on the path, and pyre check with the directory as its working directory. Output, errors and exit statuses are captured into the log.

OptionWhat it does
codebase_pathThe directory of Python code to hand to the selected tools. Required; a run without it exits 1.
--bandit / --flake8 / --pylint / --pyreSelect which external analyzers to start. Each must already be installed.
--versionPrints the program name and version, main.py 1.0.0.

What the relay does not do

  • The repository name promises obfuscation analysis. No obfuscation specific detection exists in the code: the wrapper starts other tools and logs them, and the tools it starts are general security and quality analyzers. This site claims nothing more.
  • A selected tool's own findings exit is logged and the wrapper still exits 0, because the exit code answers only whether every selected tool could be started.
  • A run with no analyzer flag selected warns that none was chosen and exits 0, having analyzed nothing.
  • A selected tool that is not installed errors by name and the run exits 1.

Requirements

Python, for the wrapper itself standard library only, plus the external analyzers named in requirements.txt: bandit, flake8, pylint and pyre-check, unpinned.
